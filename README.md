# Ultra Fx Scanner
#### Video Demo: https://youtu.be/RkxO6NjXwaI
#### Description:
Hello World!, Ultra Fx Scanner is a free to use open source forex
market scanner written in Python. It collect fundamental, sentimental and technical
data from various resourses to summarize them in a scale of -10 to 10 along with the buy or sell recommendation.

Supported Currency Pairs :

    "EURUSD", "GBPUSD", "AUDUSD", "NZDUSD", "USDCAD", "USDCHF", "USDJPY",
    "EURGBP", "EURAUD", "EURNZD", "EURCAD", "EURCHF", "EURJPY", "CHFJPY",
    "GBPAUD", "GBPNZD", "GBPCAD", "GBPCHF", "GBPJPY", "CADCHF", "CADJPY",
    "AUDNZD", "AUDCAD", "AUDCHF", "AUDJPY", "NZDCAD", "NZDCHF", "NZDJPY"


Financial Data Used For Evaluation:

- Interest rates
- GDP growth rates
- Inflation rates
- Unemployment rates
- Non-Commercial COT reports
- Retail Traders Sentiment
- Technical Indicators (TradingView)


**Note: Trading in foreign exchange (“Forex”) on margins entails high risk and is not suitable for all investors. Past performance is not an indication of future results.**


### Installation & Usage:

Step 1: Download source code and install requirements.txt
```bash
  pip install -r requirements.txt
```
Step 2: Go to root directory of code
```bash
  cd my-project
```
Step 3: Run the program
```bash
  python project.py
```
Step 4: Enter the currency pair name and wait for the magic

### FAQs:

**What is the accuracy rate?**

*Our application will only give you a bias after evaluating
Fundamental, Sentimental and Technical data. So accuracy rate
will depend on your trade entry and how you use program's info.*

**Is this program suitable for newbies?**

*Yes, New trader can use this program to understand the forex
market but they should not blindely buy or sell for any random
scores of program.*
